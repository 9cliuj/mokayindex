隐私政策

游戏可以离线运行。我们希望用清楚的文字，说明你的进度保存在何处，以及联系支持时会涉及哪些信息。

最后更新：2026 年 10 月 9 日 · 适用于当前 iOS 版本

适用范围数据收集本地存档广告与付费问题反馈网站访问政策更新联系我们

1. 适用范围

《猫猫打罐罐》是一款可离线游玩的单人游戏，由 [待填写开发者名称] 提供。本政策说明当前 iOS 游戏应用及本支持网站涉及的数据处理方式。

2. 游戏应用的数据收集

当前版本不通过游戏应用收集或上传个人数据，不提供账号注册或登录，不接入广告、用户追踪或第三方数据分析 SDK。

游戏不请求相机、麦克风、定位或通讯录权限。游戏代码、图像和音频资源随应用安装，游玩无需联网。

3. 本地存档

以下信息保存在你的设备上，用于继续游戏和保留你的偏好：

  • 巡游进度、金币、能力与永久成长；
  • 成就、最高分和其他游戏纪录；
  • 音乐、音效及减少动态效果等设置。

这些存档不会上传至开发者服务器。当前版本没有提供云存档或跨设备同步服务。

删除应用会删除其本地存档。继续巡游时，会从已保存的当前站起点重新开始。

4. 广告与付费

当前版本没有广告、应用内购买或订阅。游戏中的商店仅使用游玩获得的金币兑换游戏内物品，不涉及真实货币支付。

5. 主动提供的问题反馈

如果你通过邮箱联系我们，我们会收到你主动提供的邮箱地址、邮件内容，以及你选择附上的截图、设备信息或其他材料。这些信息仅用于理解、处理和回复你的反馈，不用于广告或用户追踪。

请勿发送与游戏问题无关的敏感信息。你可以通过下方邮箱提出删除相关反馈信息的请求；我们会根据适用要求处理。

6. 支持网站的访问

本网站是静态信息页面，没有添加访客统计、广告、追踪脚本、表单或 Cookie，也不读取游戏存档。

网站由 GitHub Pages 托管。GitHub 表示，访问 GitHub Pages 网站时，会记录访客的 IP 地址以用于安全目的。有关托管服务的数据处理，请参阅 GitHub 隐私声明。这与游戏应用本身的数据处理分开。

7. 政策更新

如果未来版本的数据处理方式发生变化，我们会更新本政策及相关商店隐私说明，并调整页面上的最后更新日期。
